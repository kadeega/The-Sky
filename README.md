# The-Sky

The Sky is a front-end website that allows users to explore astronomical events and discover celestial phenomena in an easy and engaging way. The website organizes events into three main sections: **Today, Upcoming, and Already Happened**, helping users follow astronomical events based on their timing.

It also provides access to **NASA's Astronomy Picture of the Day (APOD)**, which changes daily and includes information and details about the featured image.

Additionally, the website allows users to search for a specific country to view astronomical events that can be observed in its sky.

**Features**

* Display astronomical events.
* Organize events by date.
* Search for a country.
* View NASA's Astronomy Picture of the Day (APOD).
* Responsive design for different screen sizes.
* Clean and modern user interface.

**Technologies Used**

* HTML
* CSS
* JavaScript
* NASA APOD API
* JSON
